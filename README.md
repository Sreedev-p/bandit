### Module 2: Continuous Distributions & Sampling (The Second Half)

Since your portion starts at the Uniform distribution, you can completely ignore the discrete distributions (Binomial, Poisson, etc.) for this exam. You need to bookmark and tab the following continuous distributions and their core properties (PDF, CDF, Mean, Variance):

* **Uniform and Normal distributions**.


* **Exponential, Gamma, and Weibull distributions**.


* **Central Limit Theorem (CLT)**. Ensure you have a clear definition of how it allows you to approximate the normal distribution for large samples.


* **Sampling Distributions (t, F, Chi-square)**. The syllabus specifies *concept only* for these, so flag the theoretical definitions and properties rather than heavy calculation examples.



**Preparation Tactic:** Create a single-page cheat sheet containing just the formulas for the mean, variance, and density functions of these five continuous distributions. Next to each, write a one-line trigger for when to use it (e.g., Exponential = time between events, Weibull = failure rates/reliability).

### Module 3: Testing of Hypothesis (The Core Calculation Section)

This is where you will likely spend the most time calculating. You need a clear decision tree for which test to use.

* **Hypothesis Formulation:** Null vs. Alternative hypotheses, Simple vs. Composite.


* **Error Types:** Type I and Type II errors. Think of a Type I error (false positive) like a web application firewall dropping legitimate user traffic, and a Type II error (false negative) like a deterministic proxy failing to catch an actual payload.


* **Parametric Tests:**
* **Z-test:** For single and two population means (large sample, $n \ge 30$, or known population variance).


* **t-test and paired sample t-test:** For single and two population means (small sample, unknown variance).


* **F-test:** For testing the difference between two population variances.




* **Non-Parametric/Categorical Tests:** Chi-square test for Goodness of fit and independence of attributes.


* **Confidence Intervals:** Constructing and interpreting them.



**Preparation Tactic:** Organize your hypothesis testing notes into a flowchart.

1. Are you testing means, variances, or categorical frequencies?
2. If means, is it one sample or two?
3. If two, are they independent or paired?
4. Is the sample size $\ge 30$?
Having this visual map will stop you from second-guessing whether to use a Z-test or a t-test under pressure. Also, make sure your t-tables, F-tables, and Chi-square distribution tables are printed, clearly tabbed, and easily accessible.
